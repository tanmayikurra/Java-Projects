# PaceCalculator
The PaceCalculator Java program calculates the average pace of a race based on user input. It allows users to select a race distance and input their
race completion time in the format HH:MM::SS. The program then computes and displays the average pace per mile or kilometer, depending on the selected race distance.

# Triangle Area
The TriangleArea Java program calculates the area of a triangle given its three sides. It uses the lengths of the sides input by the user to compute the area using Heron's formula.

# Triangle Type
The TriangleType Java program determines the type of a triangle based on the lengths of its sides. It classifies the triangle as Equilateral, Isosceles, or Scalene, and optionally 
provides additional information such as height, perimeter, or area based on the triangle type.
